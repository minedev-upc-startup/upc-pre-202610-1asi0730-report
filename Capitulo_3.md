# Capítulo III: Requirements Specification

En base al proceso de investigación realizado en el Capítulo II —entrevistas con Propietarios de maquinaria y Clientes del sector minero, análisis de necesidades y construcción de los User Personas— el equipo identificó y priorizó los requisitos del marketplace de alquiler de maquinaria pesada MineTrack. Esta sección presenta las Epics, User Stories y Technical Stories que definen el alcance funcional del producto, junto con el Impact Mapping y el Product Backlog priorizado.

Las User Stories cubren tres productos digitales del alcance: la **Landing Page** (sitio web estático de presentación pública), la **Web Application** (plataforma autenticada con roles Propietario, Cliente e Intermediario) y los **Web Services** (API REST construida en ASP.NET Core). Para los Web Services se incluyen Technical Stories con el rol Developer. Los criterios de aceptación siguen la estructura Gherkin (Given-When-Then), están redactados en tiempo presente y tercera persona, y no hacen referencia a detalles de interfaz de usuario.
